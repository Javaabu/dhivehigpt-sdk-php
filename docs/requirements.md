title: Requirements
sidebar_position: 1.1
---

This package requires the following:

- PHP 8.0 or higher
- The `json` PHP extension (enabled by default in most PHP installations)
- [Guzzle](https://docs.guzzlephp.org) 7.0 or higher (installed automatically as a dependency)

Laravel is **optional**. The SDK works standalone in any PHP application. If you do use Laravel, the following versions are supported:

- Laravel 9, 10, 11, 12, or 13
